# Drizzle вместо TypeORM для доступа к Postgres

Для NestJS «родной» выбор — TypeORM, но у него слабее типизация запросов и хуже репутация миграций. Ключевые
инварианты домена (один Слот — одно Бронирование, Лимит бронирований на email в день) требуют явных транзакций
и `SELECT … FOR UPDATE`. Drizzle даёт это напрямую, оставаясь типизированным, а миграции генерирует `drizzle-kit`.

## Considered Options

- **Prisma**: популярнее, но блокировку строк пришлось бы писать сырым SQL в обход типизации.
- **TypeORM**: интеграция с Nest из коробки, но названные выше минусы.
